## 2. 六类共享语义槽

### 槽 1：地质单元槽（QDUECC / QDUECD + DDCDII 族）——组合式编码 DSL

- **覆盖率**：三幅 QDUECC 含箭头记法 100%（库 608/英 524/奥 417 全部）。
- **语法**（三幅共用一个组合文法）：

```
→时代码[↓亚统/世][→|↑][-]单元代号[↑成因码][段号修饰]
例：→D↓2→t（中泥盆统 托格买提组）｜→Qp↓3↑eol（上更新统 风积）｜
    →Qp↓3→-h↑fl（上更新统 湖积-过渡型）｜→Qp↓3→X（西域组）｜→P↓1-2→h↑1（下-中二叠统 第1段）
```

- **语法共享、词项私有**：时代-token（D/Qp/Qh/J/P/C/T/S/O/Ch/Pt/Ar…）跨幅通用；单元代号（t/s/kz/X/Y…）图幅私有（本幅地层表）。
- 配套字段：QDUECD（单元中文名，自由文本）、DDCDII（数字年代区间码：`边界码[-边界码]*[>下界]`，如 `121109-121138`、`111654-111500>121400`）、DDCDIL（地层分区文本）、MDBRS（化石内容文本）。

## 3. 内在共性：词表成熟度三级模型

跨幅比较揭示这套数据的**词表三级成熟度**——这正是"标定"必要性的结构根源：

| 级 | 词表 | 性质 | 跨幅处理 |
|---|---|---|---|
| **L-A 国标稳定词表** | GZBD、GZELD、GZBBGA、GZCE、GB、GZEEC | 闭集、跨幅同义 | 可直接映射（注册表预置） |
| **L-B 图幅私有词表** | **GZEEB**、CHFCEC 类目 | 码面同构、码义随幅 | **必须本幅标定**（三层逻辑 L1→L2→L3 已建）；01/05/16 为跨幅"锚码"（泛称/逆/走滑——统计上三幅同义） |
| **L-C 组合式 DSL** | QDUECC（单元码）、DDCDII（年代码） | 文法共享、词项私有 | 通用解析器+本幅地层表词项 |

## 4. 数据质量层的共性瑕疵模式

三幅同型出现、可模式化处理的瑕疵类：

1. **同槽混用**：GZCCAE 文本方位（'南倾'）×角度值（'225'）；GZECD 角度值×区间文本（'360-180'）；
2. **变体字符**：西里尔 г=γ 误录、∑ 数学符（奥 48 面元实证）；
3. **完备度梯度**：同一语义槽填充率跨幅悬殊（GZECD 库 0%/英 35 值/奥 10 值；GZEHH 奥 20% 有值/库英全空）——**判据适用域原则**的结构依据：任何依赖单槽的判据必须先验空槽率；
4. **文本-码混排**：GZEHG 单元码×自由描述混排（恰是蛇绿混杂带等自证信息的载体——不应清洗而应解析）。

## 5. 共性数据结构形式化（地质语义实体模型）

由普查归纳的**跨幅统一语义实体模型**（三层逻辑与 GeoSciML 转换的结构底座）：

```
GeologicUnit（地质单元，面元）          —— QDUECC(DSL) + QDUECD + DDCDII(年代区间)
  ├─ 地层单元（BB001 沉积/BB002 火山/BB004 变质）  └─ 地质体（BB003 侵入岩）
Contact（地质接触，界线）               —— GZBD(L-A 词表) + 两侧单元对（面元拓扑）
ShearDisplacementStructure（断层）      —— GZEEB(L-B 私有词表→本幅标定) + GZELD(L-A 运动学)
                                          + GZECE/GZECD(产状) + GZEHG(切割体)
Fold（褶皱）                            —— GZCE(L-A) + GZCAB(名) + GZCCAE(轴面倾向)
OrientedObservation（定向观测，产状）   —— GZBBAB/AC/AD(走向/倾向/倾角) + GZBBGA(面理类型)
                                          + symbol_no(符号-语义绑定)
FaultAuxPoint（断层辅助测量点，BB099）  —— CHFCEC(类目,图幅标签系) + CHFCED(注释文本)
                                          + symbol_no(1894 箭头/1281 双短线/238·239 钩/1882·1883/1851)
                                          + angle(符号旋转角)
Cover（覆盖要素，水系）                 —— GB(73020 冰川 ∪ 第四系面元→覆盖证据链)
```

## 6. 与既有架构的呼应

1. **六步契约的 11 文件选择被普查证实**：三幅 schema 完全一致 → 预检契约（preflight SCOPE_FILES）是结构事实而非约定；
2. **三层逻辑的词表分级落地**：L-A 词表=注册表预置语义；**L-B 词表（GZEEB/CHFCEC）=三层标定的核心对象**（段级 MLE→码级映射表→全继承）；L-C DSL=通用解析器（_unit_age_rank/name_segment 等已在生产）；
3. **判据适用域原则再证**：完备度梯度（GZECD/GZEHH）与标签体系三套并存，要求一切跨幅判据先验适用域——英吉沙推测断层漏判教训的同构根源；
4. **瑕疵模式清单即规范化通道**：同槽混用/变体字符/文本-码混排三类瑕疵，对应 materialize 的 _SEM_NORM、配对池 CHFCEC 甄别、QDUECD 兜底等既有机制的归纳来源。
