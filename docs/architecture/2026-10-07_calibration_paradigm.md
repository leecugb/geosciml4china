## 0. 一句话范式

> **语义不在数据里，语义在先验与拓扑的对照中涌现。**
> 标定 = 用先验构造测量（假设驱动观测）→ 用统计完成推断（三级粒度）→
> 用矛盾驱动修订（证伪保持+人机协同）的收敛循环。

## 1. 四公设

### 公设 1 · 本体分层（Ontological Layering）

被标定世界按**证据独立性**分解为正交维度，各层独立标定、互不污染。

- 结构层 ⊥ 活动层 ⊥ 证据层（GZEEB 三维分层）——F117.2：结构=推覆体边界（码义继承）与活动=活动（段级保留）**同真不冲突**，正因两层正交；
- 域间同构：GZBD 与 GZEEB 同走三层逻辑（先验属 L1 算法，码级语义另行判定）——分层是域间可迁移的结构，不是断层域的偶然。

### 公设 2 · 统计分层（Statistical Hierarchy）

推断按统计粒度三级，**上级对下级拥有最高优先级**：

| 级 | 粒度 | 机制 | 型例 |
|---|---|---|---|
| L1 样本级 | 段 | 自支持 MLE 投票 + 强证据规则 | F049.1 段级老盖新→推覆候选 |
| L2 总体级 | 码 | 全局最大似然 + 注册裁定（三源优先级） | 01 码无族义→断层泛称 |
| L3 演绎级 | 同码全体 | 表驱动全继承（一般断层兼容一切） | F049.1 终态=断层泛称 |

这是统计学的经典三段论：**局部证据定样本，样本聚合定总体，总体结论演绎回样本**。类别编码值拥有最高优先级——L2 一经标定，L1 的段级分歧从"结论"降格为"供统计与留档的证据"。

### 公设 3 · 关系即观测（Topology as Observation）

编码值本身是**待标定的标签**，不携带语义；语义证据来自**数据结构关系与先验知识的对照测量**：

| 拓扑关系 | 测量形态 | 判别目标 |
|---|---|---|
| 面元-线探针 | 7 点×±300m 双侧采样 | 接触类型/新老序/推覆 |
| 线-线重合 | 断层接触重合度、Q 边界重合 | 路由/活动断层标志 |
| 线-面包含 | Q 内比例、冰雪覆盖 | 推测断层/证据分级 |
| 点-线邻近 | 辅助点→实体链（弧长/侧别/距离带） | 归属/测量点语义 |
| 点-点配对 | 钩对/三联体/注释依附 | 旋向/倾滑/倾角 |

**假设驱动观测**：先验决定"测量什么"——没有接触先验表，就没有探针的必要性；没有 1894 箭头的倾角语义，就没有 1:1 注释配对。测量是知识对数据提出的问题。

### 公设 4 · 证伪保持（Falsification Preservation）

矛盾是标定的**产出**而非故障：期望核对**后置**（EXPECT × 继承后终态语义）、一段一条登记、pending_review、**永不自动改码**。数据本体保持原样；修订只发生在语义层与登记层——缺陷走「发现→归因→裁定→覆盖库→自动应用→复检」闭环（原始 WP 不改写）。标定与缺陷修复互为收敛：拟合与数据不符处，正是缺陷所在。

## 2. 收敛循环

```
        ┌────────── 先验注入（假设层）──────────┐
        │ 接触先验表 / 时代rank / 码义注册表 /    │
        │ 用户裁定（覆盖库·user_semantic）        │
        ▼                                        │
   拓扑测量（观测层：五类关系通道）               │
        ▼                                        │
   统计标定（推断层：L1→L2→L3 三级）             │
        ▼                                        │
   期望核对（证伪层：EXPECT×终态语义，后置）      │
        │                                        │
        ├─ 不符 → 矛盾登记（pending_review）      │
        │          → gap_report 配图 → 人工裁定 ──┘（修订注入）
        └─ 相符 → 出站（GeoSciML/渲染/映射表）
```

**验证环**（贯穿全程，保证可再现）：确定性重放（编辑→重跑→回退逐字节回归）、A01-A27 业务断言、C1-C7 镜像对账、三层契约测试（同码终态唯一性/映射表覆盖一致）。

## 3. 与科学方法论的同构

| 科学方法论 | geosciml4china 对应 |
|---|---|
| 假说（Hypothesis） | 先验：接触表/EXPECT 期望/码义注册 |
| 观测设计（Observation design） | 拓扑通道选择（假设驱动） |
| 似然（Likelihood） | MLE 投票（先验+3/名+2/签名+2/aux+2/倾角域+1/覆盖+2~3） |
| 统计检验（Testing） | ≥25% 主导门槛、复活签名 min/max≥0.5、1:1 最优指派 |
| 证伪（Falsification） | 期望核对后置、矛盾登记、永不自动改码 |
| 理论修订（Theory revision） | 人裁定入注册表/覆盖库/映射表（人机协同：机器做可计算部分，人做地质判断） |
| 可再现（Reproducibility） | 确定性重放 + 镜像对账 + 断言网 |
| 置信度（Confidence） | S×I×F（语义强度×证据独立性×拟合优度） |

本质：**波普尔假说-演绎（证伪保持）× 贝叶斯分层更新（注册表=先验、段级=似然、码级=后验，映射表 user_semantic=后验固化）× 人机协同科学**的工程化。

## 4. 范式的迁移性（词表三级成熟度）

范式对不同数据禀赋的适用度分级——接入任何新编码制图数据先验三审：

| 词表成熟度 | 禀赋 | 范式形态 |
|---|---|---|
| L-A 国标稳定词表（GZBD/GZELD/GZBBGA） | 码义跨幅同义 | 注册表预置 + 统计验证（轻标定） |
| L-B 图幅私有词表（GZEEB/CHFCEC 类目） | 码面同构、码义随幅 | **三层逻辑全链**（范式完整形态） |
| L-C 组合式 DSL（QDUECC/DDCDII） | 文法共享、词项私有 | 通用解析器 + 本幅词项表 |

新幅接入三审（英吉沙教训固化）：①码义注册表（本幅模式优先）②判据适用域（完备度梯度——GZECD 0%/35 值/10 值型差异决定判据可否继承）③语义维度（三维分层不塌缩为一维）。
