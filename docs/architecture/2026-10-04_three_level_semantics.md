# 三层地质语义标定-转换逻辑（2026-10-04 定版）

> 用户对齐定版的三层逻辑：
> **第一层次**，自支持判别逻辑用于段级别的编码值的地质语义标定；
> **第二层次**，项目在全局层面基于编码值与地质语义的统计关系，以最大似然原则最终标定编码与地质语义的映射关系；
> **第三层次**，所有数据按照第二层次标定的编码-地质语义映射表转为基于地质语义的 GeoSciML。

本文档固化三层逻辑的职责边界、机制、产出物与代码位置，并以 F049.1 / F117.2 / F106.1 三案走查。与《六步架构契约》（2026-10-02 用户对齐）的对应见 §6。

---

## 1. L1 段级标定——自支持判别逻辑

**「每段断层自己说话」**：以段为独立样本，用自支持证据（不依赖码义先验）做 MLE 投票标定。

### 证据通道（MLE 投票权重）

| 通道 | 权重 | 说明 |
|---|---|---|
| 注册先验 | +3 | 码义注册表先验票（仅 L1 投票用；L2 另有最高优先级） |
| 断层名性质 | +2 | 名称含性质词（如「逆断层」） |
| 推测签名 | +2 | 全段无实测倾角+覆盖支撑码型 |
| GZELD 运动学 | +2 | 压/张/剪 × 结构语义成因联系 |
| 倾角域 | +1 | 实测倾角落语义期望域 |
| aux 产状点 | +2 | 断层产状注释点判别（CHFCEC 甄别池） |
| 覆盖 | +2~3 | Q 内/冰雪覆盖（界线重合闸——Q-地层界线段禁投） |
| Q-界线重合 | +2~3 | 弱重合/强档，直投活动断层 |

### 强证据即标定（无需人工裁定）

- 老盖新（倾向盘 rank < 下盘 rank）→ **推覆体边界**；
- 走滑码 × 倾滑 aux 同段命中 → **复合断层**升格（双分量如实合载）；
- Q-地层界线重合三档（长距离/多段/单段强型）→ **活动**晋升。

### 三轴同标（每段三个独立维度）

| 轴 | 取值 | 标定依据 |
|---|---|---|
| 结构层 | 正/逆/推覆/走滑/复合/活动/推测/断层泛称 | MLE 投票众数 + 强证据规则 |
| 活动层 | 活动/未评 | Q-界线重合三档自动标 |
| 证据层 | 实测/部分覆盖/推测 | 覆盖度分档 |

### 产出

段级标定分布（`_mle_raw`）→ 提案表 `_gzeeb_code_semantics_proposal_<key>.csv` 的 **mle_distribution** 列——L2 的统计原料。

**位置**：`calibrate/gzeeb.py` 主投票循环。

## 2. L2 码级映射表——全局最大似然

**「全幅段落完票，码才有义」**：L1 全段标定按编码值聚合，以统计主导性判定 码→语义 映射。

### 族义判定

- 决定性语义（正/逆/推覆/走滑/活动等）须覆盖族内 **≥25%** 段方成族义（01 码 11/131 老盖新=8% 不足判推覆案，2026-10-03 裁定）；
- 断层泛称/推测断层不计入族义分子（兜底类与证据轴类）。

### 结构规则

- **逆断层一幅一码**（2026-10-04 裁定）：逆断层段数居首的未注册码主张逆断层语义，其余码剔除逆断层候选；
- **复活签名**：剔除逆候选后，正逆共存且可比（双向各 ≥3 且 min/max ≥0.5）→ **活动断层**（jwsss 31 案 9:6=0.67 成立；jwsss 01 案 34:3=0.09 不成立）。

### 三源优先级

```
注册表（人工裁定，fault_semantics_<key>.json）
  > 签名通道（推测断层码型，_sig_infer）
  > MLE 逻辑判断（_mle_sem_by_code）
```

### 无族义 → 断层泛称（null 语义）

码无族义时映射为**断层泛称（一般断层）**——一般断层**兼容所有矛盾信息**（2026-10-04 裁定）：`EXPECT[断层泛称]=∅`，任何段级证据对泛称映射零冲突登记。兼容性不是豁免规则，而是数据模型的天然推论。

### 产出与反馈环

- **产出**：编码-地质语义映射表（`_mle_sem_by_code` → 提案表 **mle_semantic** 列）；
- **反馈环**：提案表 → 人工裁定 → 注册表写入 → 下轮 L2 精化（码义提案注册裁定队列在冲突册 informational 条目跟踪）。

**位置**：`calibrate/gzeeb.py` 后处理段（`_mle_sem_by_code` 构建）。

## 3. L3 表驱动转换——全继承物化 + GeoSciML 出站

**「数据 × 映射表」**：映射表应用到每一个同码要素（全继承），转换与渲染只消费语义。

### 物化时点

映射表在**标定阶段即回填**段级 `structural_type`（六步契约④「同编码值继承相同地质语义，转 L1 级 geojson」裁定）——表在 L1 落地，下游免 join；L1 `faults.geojson` 的 structural_type 即 L2 映射的物化。

### 继承规则（2026-10-04「类别编码值拥有最高优先级」裁定）

| 情形 | 处理 |
|---|---|
| 码义=断层泛称 | 全段压平泛称，**不登记**（一般断层兼容一切；证据留 checks 备查） |
| 码义=具体语义，段级一致 | 不动 |
| 码义=具体语义，段级分歧 | 压平继承 + **「码义全继承」登记**（段级证据如实入册待裁定） |
| 覆盖库裁定段 | **不动**（人工裁定绝对，L0 > L2） |

### 核对后置

段证据 × 终态语义的期望核对（倾角域/aux 期望/钩旋向/新盖老/GZELD 运动学）**在继承后统一执行**：

- 泛称映射：零登记（兼容）；
- 具体映射：违反入册（与「码义全继承」合并去重——**一段一条**）→ 专家裁定队列；
- 效应：核对既吸收假矛盾（F049.1 案 dip=50°），也显形真张力（jwsss F067/F048 案——段级泛称时代免检的 05 码×aux正 冲突）。

### 语义出站

- GML：`structural_type`（语义槽）、`faultType`（**语义驱动**——`mapping.faulttype_by_semantics`，图幅级映射文件在场时码查表优先以保正典契约）、`movementSense`（GZELD 三层同构出站）、description（活动层/界线证据/矛盾横幅注记）；
- 渲染：渲染引擎按继承语义成图（structural_type → 样式单源）。

**位置**：`calibrate/gzeeb.py` 继承段+核对后置段 → `materialize`（L1 物化）→ `convert/build.py`（GML）→ `render/`（成图）。

| 轴 | 层次路径 | 型例 |

## 5. 型例走查

### F049.1（jwsss，01 码）

- **L1**：老盖新（倾向盘 503 老于下盘 901）+ 地层重复 + dip=50°（双源互证）→ 段级**推覆体边界**；
- **L2**：01 码 155 段无族义（泛称兜底类主导）→ **断层泛称**；
- **L3**：继承泛称；dip=50° 对泛称无期望 → 兼容零登记；GML `structural_type=断层泛称`+`faultType=fault`；渲染一般断层灰线无横幅。

### F117.2（jwsss，07 码）

- **L1**：Q 内 100% + Q-地层界线重合 2923m/100%（单段强型）→ 段级**活动断层**；活动层=活动；证据层=推测；
- **L2**：07 码 3 段老盖新锚定（F117.1 为锚段之一，25° 缓倾 verified）→ **推覆体边界**；
- **L3**：结构继承推覆（`faultType=thrust_fault`）+ 活动层保留（描述出站「活动性：活动断层」）+ 结构轴向分歧「码义全继承」入册待裁定。地质图景：山前推覆前锋——结构上推覆体边界与活动性并存，三维分层如实合载。

### F106.1（jwss，01 码——裁定源头案）

- 段级曾误持推覆票（median_pref 误归属 aux=242 所致，倾向侧通道纠正后票失）；
- 用户裁定：F106.1 继承 jwss 标定的 01=一般断层，而非自身特定情况——此裁定后提升为普适原则（全继承）与最高优先级原则（码义 > 段级自证）。

## 8. 编码-地质语义映射表：修改-再转化回路（2026-10-04 定版）

**L2 映射表是一等公民工件**：geosciml4china 给出清晰完整的映射表，允许用户修改，支持修改后再转化数据。

### 工件

| 文件 | 域 | 说明 |
|---|---|---|
| `<root>/code_semantics_map_<key>.csv` | GZEEB | 全码一表（9/7 码×双幅） |
| `<root>/gzeld_semantics_map_<key>.csv` | GZELD | 运动学码一表 |

列（GZEEB 表）：`GZEEB, segs, semantic, source, confidence, mle_distribution, final_distribution, evidence_votes, user_semantic, user_note`

- **semantic**：当前生效码义（继承口径同源）；
- **source**：注册表 / 用户修改 / 签名 / MLE逻辑判断 / MLE无族义（泛称） / 统计推导（GZELD）；
- **confidence**：裁定分诊分级——强证（≥20 段且有效证据≥50%）/ 中证（≥10 段，或 ≥5 段且有效≥25%）/ 薄证（其余；有效=own 分布剔除泛称/推测的决定性证据段占比）；注册表=裁定固化、签名=签名码型、无族义=兜底；
- **mle/final_distribution**：L1 段级标定分布 / L3 继承后终态分布（三层逻辑在纸面上可读）；
- **evidence_votes**：纯证据票仓（aux/data/act 三通道分组——**剔除注册先验票**，消除先验回声/伪互证读表风险）；
- **user_semantic**：**用户修改列**——填写即覆盖 semantic（下轮标定生效；编辑跨轮保留——重写映射表时原值带回）；
- **user_note**：用户裁定备注（同样跨轮保留）。

### 消费优先级

```
JSON 注册表（fault_semantics_<key>.json，裁定固化档案）
  > CSV user_semantic（工作修改通道）
  > 签名通道（推测断层码型）
  > MLE 逻辑判断
```

注册表码与 user_semantic 并存时注册表优先并打印告警（建议定稿修改迁入注册表固化）。

### 修改-再转化回路

```
① 编辑 code_semantics_map_<key>.csv 的 user_semantic（Excel/WPS 直接改）
② g4c calibrate-gzeeb --sheet <key>        # L1/L2 确定性重放，编辑生效
   （继承/核对后置/冲突册/映射表全部重算；A23 基线若变需同步 verify.py）
③ g4c pipeline --sheet <key> --skip-convert --skip-calibrate-stages
                                            # 物化→GML→verify→渲染
```

- **单一代码路径**：编辑不引入第二条实现路径，消除分叉风险；
- **陈旧守卫**：pipeline 检测映射表显著新于校准件（>60s）时打印提醒，防止编辑后漏跑 ②；
- **段级自证可读**：校准 CSV 的 `own_structural_type` 列（L1 结果）与 `structural_type`（L2/L3 终态）并列，三层分层在数据件上直接可审计；
- **端到端验证在案**（2026-10-04，jwsss 16 码 右型走滑断层→正断层 编辑测试）：段 131 继承正断层、own 保留右型走滑、「码义全继承」登记与钩对张力合并（一段一条）、映射表 source=用户修改 回写；清空 user_semantic 重跑后逐字节回归。

### 与注册表的分工

| 通道 | 角色 |
|---|---|
| `fault_semantics_<key>.json` | 裁定**固化档案**（含 verified 溯源注记；L1 先验票来源） |
| `code_semantics_map_<key>.csv` | **工作映射表**（全码可视、可改；日常修改-再转化入口） |
| `_gzeeb_code_semantics_proposal_<key>.csv` | MLE 诊断证据（投票分通道计数；不消费） |

## 9. GZBD 界线域三层逻辑（2026-10-04 用户裁定：GZBD 同样需要标定）

**关键澄清**：`boundary_contact_priors.json` 注入的先验知识属 **L1 标定算法**（双料最高知识源进入段级判别），不是 L2 码级语义的替代品——GZBD 与 GZEEB 同构，同样走三层逻辑。

### 三层映射

| 层 | GZBD 落地 | 工件 |
|---|---|---|
| L1 | 段级界线标定（先验注入+两侧探针+新老关系+分支规则）→ 段级标签 | `_gzbd_semantic_interpretation.csv`（`标定语义` + **`原标定语义` own 留档**） |
| L2 | 码级语义=**用户裁定级**（注册表 user_confirmed/图幅 decided/user_semantic）> **MLE 段级统计精化**（主导具体标签 ≥25%——01 码 整合接触 52% 主导即精化案例）> **注册先验泛义兜底**；标签经 canon 口径（同义折叠+可选「界线」后缀忽略）防展示变体假分歧 | `boundary_semantics_map_<key>.csv`（全码一表：semantic/source/confidence/national_label/contactType_term/label_distribution/divergent_segs/**user_semantic**/user_note） |
| L3 | 全继承：通用/存疑标签段**静默继承**码义（泛称式升级，jwsss 01 码 66 段 实测地质界线→整合接触）；具体分歧段让位+登记（`_gzbd_conflicts_<key>.csv`，jwss 24 码 4 段 平行不整合让位整合接触）；「先验建议→」建议型标签=本域自有分歧登记机制保持原样；用户裁定改码/分歧未裁定/制图误差剔除行绝对不动 | L1 `sem_label` 终态 → contacts 视图/GML/渲染；**contactType 语义驱动**（`mapping.contacttype_by_semantics`——段级终态语义→CGI 词：整合接触→conformable_contact、角度不整合→angular_unconformable、平行不整合→disconformable、不整合→unconformable、岩相接触→igneous_phase；未覆盖标签回退码查表；图幅级映射文件在场时码查表优先） |

### 码义来源优先级（GZBD）

```
用户裁定级（注册表 user_confirmed 约束［43/60 案］/ 图幅 vocab decided / 映射表 user_semantic）
  > MLE 段级统计精化（主导具体标签 ≥25%）
  > 注册先验泛义（gzbd_codes.json meaning——库尔干验证的包默认）
  > 兜底（实测地质界线）
```

### jwss 24 案（码义随幅的型例）

jwss GZBD=24（9 段）段级分布 整合接触×5 : 平行不整合×4——库尔干注册先验（平行不整合，consistent 级）不构成用户裁定级，MLE 精化判 **整合接触**；4 段平行不整合让位登记待裁定；contactType 经语义驱动对齐 conformable_contact（原码查表 disconformable 与段级语义矛盾——与 faultType 码查表缺口同型同治）。注册先验仍在映射表 `national_label` 列可视，user_semantic 可一键回退。

### A07 基线变更（2026-10-04 实测）

contactType 语义驱动后 nil 大幅收敛：jwsss 278→**80**（余侵入接触 78+推测界线 1+复合标签 1 待词表裁定）、jwss 405→**192**（余侵入接触 186 等）。
