# 1:25 万分幅建造构造图数据结构（《中国陆域1:25万分幅建造构造图空间数据库》精读）

来源：左群超、叶天竺等 2018《中国陆域 1:25 万分幅建造构造图空间数据库》
（中国地质 45(S1):1-26，doi:10.12029/gc2018Z101；729 幅/16.6GB/*.wl,wt,wp）。
**定性**：数据库建设方法论+元数据论文；**属性码表（GZBD/GZEEB/GZCE/GZBBGA 码值字典）
不在本文**——图层数据表结构与填写规定在《成矿地质背景研究数据模型》（左群超等 2011a），
图例码值在《全国矿产资源潜力评价编图统一图例规定》（左群超、杨东来 2008b）——两者均不可得，
码义仍以本项目自支持判别为准（词典到手即降为偏差定级锚）。

## 1. 图件数据结构（五部分，§3.1 表 2）

1. **图件基本概要信息**：命名模式、空间范围、比例尺、**坐标系及投影**、技术参数、
   图例/图式规定、数据格式、**计算机命名模式与代码模式、专业谱系及代码**、编图说明书、元数据。
2. **主图图层分层信息**（见 §2）。
3. **辅图**：沉积/火山/侵入/变质 4 类建造综合柱状图【可选】+图切剖面【必要/可选】
   +大地构造位置角图、地层分区角图。柱状图图头结构官方定义（图 5/7/8）。
4. **附表**：大地构造分区表【必要】、地层分区表、大型变形构造特征表、第四系成因类型划分表【可选】。
5. **整饰图层**：标题、比例尺、方向标、图例说明、投影参数说明、技术参数及资料来源、责任表。

**坐标系规定（§2.4）**：北京 54 坐标系、1956 黄海高程、高斯 6° 分带、投影原点纬度 0°
——即原始 MapGIS 数据为北京 54 六度带投影坐标；本项目渲染/转换统一重投影至
WGS84 UTM 43N（EPSG:32643）是合法后处理（正形保角）。

## 4. 建造概念（编图核心，§2.1.2/§2.1.4）

- 建造三层级：**岩性/岩石组合**（成控岩构造）→ **岩石建造**（区域构造；沉积/火山/侵入/
  变质四类，建造构造图基本编图单元）→ **岩石构造组合**（大地构造相图单元）。
- **建造构造图核心 = 组级岩石地层单位进一步细分为建造**（"组一级单位不能归并，
  地质信息优于图面表达"）；按产状表达建造花纹。
- 火山岩区按**岩性岩相双重填图法**；侵入岩区必须表达**深成岩体解体后的侵入体**；
  变质岩区区分变质表壳岩/变质深成侵入体。
