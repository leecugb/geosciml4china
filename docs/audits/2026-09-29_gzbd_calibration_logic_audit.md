## 4. 审计中发现并修复的缺陷

| # | 缺陷 | 性质 | 修复 |

| D1 | 面元装载存在性闸只查 MapGIS 文件路径（root/*.WP），L0-only 图幅（合成/测试/无原生件场景）四文件全跳过→tree 空→探针全空→全线未覆盖静默降级 | 真缺陷（移植时未暴露：库尔干等实幅有原生件） | 闸改双路径（root 与 geojson/L0 同口径，与冰雪闸一致） |
